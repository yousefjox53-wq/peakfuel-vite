# PeakFuel Vite

React + Vite demo e-commerce site for gym supplements with WhatsApp checkout.

How to run locally:

1. npm install
2. npm run dev

Build for production:

npm run build

Notes:
- WhatsApp checkout opens a fixed store number: https://wa.me/2010XXXXXXXXX?text=...
- Discount code: yousef10 → 10% off
